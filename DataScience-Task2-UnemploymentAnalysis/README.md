# Unemployment Analysis with Python

## Objective
The objective of this project is to perform Exploratory Data Analysis (EDA) on India's unemployment dataset to understand regional and temporal unemployment trends and analyze the impact of the COVID-19 pandemic on unemployment rates.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
- Unemployment in India Dataset (Kaggle)

## Project Workflow
1. Import required libraries
2. Load the dataset
3. Inspect dataset (shape, info, null values)
4. Data cleaning and preprocessing
5. Exploratory Data Analysis (EDA)
6. Region-wise unemployment analysis
7. Month-wise unemployment trend analysis
8. Time-series visualization for major states
9. Top 10 states with highest average unemployment rate
10. Correlation heatmap
11. Pre-COVID vs Post-COVID unemployment comparison
12. Conclusion

## Visualizations
- Region-wise Average Unemployment Rate
- Monthly Unemployment Trend
- Time-Series Line Chart
- Top 10 States Bar Chart
- Correlation Heatmap
- Pre-COVID vs Post-COVID Analysis

## Results
- Analyzed unemployment trends across different regions.
- Identified states with higher unemployment rates.
- Visualized monthly unemployment changes.
- Compared unemployment before and after COVID-19.
- Found correlations between unemployment, employment, and labour participation rate.

## Conclusion
This project provides valuable insights into unemployment trends in India. The analysis shows how unemployment varied across states and how the COVID-19 pandemic affected employment conditions. The project strengthened practical knowledge of data preprocessing, exploratory data analysis, visualization, and time-series analysis using Python.
