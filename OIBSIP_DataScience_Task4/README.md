# Email Spam Detection

## Objective
The objective of this project is to build a machine learning model that classifies messages as Spam or Ham (Not Spam).

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning Algorithm
- Multinomial Naive Bayes

## Project Workflow
1. Data Loading
2. Data Cleaning
3. Exploratory Data Analysis
4. Text Preprocessing
5. TF-IDF Vectorization
6. Train-Test Split
7. Model Training
8. Prediction
9. Model Evaluation
10. Confusion Matrix Analysis

## Results
- Accuracy: 96.86%
- Successfully classified spam and non-spam messages.
- Generated confusion matrix and classification report.

## Conclusion
The Multinomial Naive Bayes model achieved excellent performance in detecting spam messages. This project demonstrates the practical application of Natural Language Processing and Machine Learning for text classification.
