# Car Price Prediction

## Objective
The objective of this project is to predict car prices using Machine Learning based on different car features.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning Algorithm
- Random Forest Regressor

## Project Workflow
1. Import Libraries
2. Load Dataset
3. Data Cleaning
4. Exploratory Data Analysis (EDA)
5. Data Visualization
6. Label Encoding
7. Train-Test Split
8. Model Training
9. Prediction
10. Model Evaluation
11. Feature Importance Analysis

## Results
- Successfully predicted car prices.
- Model achieved an R² Score of approximately **95.54%**.
- Engine Size, Horsepower, and Curb Weight were identified as the most influential features.

## Conclusion
The Random Forest Regressor successfully predicted car prices with high accuracy. The project demonstrates the effectiveness of machine learning in solving real-world price prediction problems.
